Atlas File Manager is a file explorer for Windows. Open folders in tabs, work in two panes side by side, search inside subfolders and preview files without leaving the window. Most actions have a keyboard shortcut, and every command can be found from a single search.

• Tabs and split panes, each with its own view and history
• Search a folder and all of its subfolders
• Preview images, PDFs, Markdown, text and code beside the file list
• Convert files from a format ring, for example JPG to PNG, WebP or PDF
• Open ZIP archives like folders and preview their contents
• Details, grid, list, column and tree views
• Command palette with every action and its keyboard shortcut
• Remappable keyboard shortcuts and searchable settings
• Google Drive, OneDrive, SFTP, FTP, WebDAV and SMB in the sidebar
• Light, dark and glass themes with live preview
• Disk usage map to review large folders before cleaning up
• Batch rename with patterns and numbering
• Optional: open Atlas with Win+E instead of File Explorer

The Free edition includes up to 2 panes, 1 saved connection and 2 profiles. Batch renaming supports up to 25 files per operation. Conversion supports 1 source file per operation and 10 converted files per day. Premium removes these edition limits and requires a separate purchase.

Local file management does not require an Atlas account. Optional cloud connections require an account with the selected provider and internet access. Some previews and conversions require additional tools. Mounting encrypted private folders requires the optional WinFsp driver; ordinary file management does not.
