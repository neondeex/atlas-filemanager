Atlas File Manager は Windows 用のファイルエクスプローラーです。フォルダーをタブで開き、2 つのペインを並べて作業し、サブフォルダーまで検索して、ウィンドウを離れずにファイルをプレビューできます。ほとんどの操作にキーボードショートカットがあり、すべてのコマンドを 1 つの検索から見つけられます。

• タブと分割ペイン（それぞれ独自の表示と履歴を保持）
• フォルダーとそのすべてのサブフォルダーを検索
• 画像、PDF、Markdown、テキスト、コードをファイル一覧の横でプレビュー
• 形式リングからファイルを変換（例: JPG から PNG、WebP、PDF）
• ZIP アーカイブをフォルダーのように開き、内容をプレビュー
• 詳細、グリッド、リスト、カラム、ツリー表示
• すべての操作とショートカットを一覧できるコマンドパレット
• 変更可能なキーボードショートカットと検索できる設定
• Google Drive、OneDrive、SFTP、FTP、WebDAV、SMB をサイドバーに表示
• ライブプレビュー付きのライト、ダーク、ガラスのテーマ
• クリーンアップ前に大きなフォルダーを確認できるディスク使用量マップ
• パターンと連番による一括名前変更
• オプション: エクスプローラーの代わりに Win+E で Atlas を開く

Freeは最大2ペイン、保存済み接続1件、2プロファイルに対応します。一括名前変更は1回25ファイルまで、変換は1回1入力ファイル、1日10変換ファイルまでです。Premiumはこれらのエディション制限を解除し、別途購入が必要です。

ローカルファイルの管理にAtlasアカウントは不要です。任意のクラウド接続にはインターネットとプロバイダーのアカウントが必要です。一部のプレビューや変換には追加ツールが必要です。暗号化されたプライベートフォルダーのマウントには、任意のWinFspドライバーが必要です。
