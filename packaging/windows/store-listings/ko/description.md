Atlas File Manager는 Windows에서 파일을 탐색하고 정리할 수 있도록 돕습니다. 탭으로 폴더를 열고 분할 창에서 위치를 비교하며 자세히, 격자 또는 열 보기를 선택할 수 있습니다.

• 탭 및 분할 창
• 자세히, 격자 및 열 보기
• 파일 검색 및 폴더 필터
• 지원 형식의 파일 미리 보기
• 디스크 사용량 표시 및 정리 검토
• 패턴과 번호를 사용한 일괄 이름 변경

Free는 최대 창 2개, 저장된 연결 1개, 프로필 2개를 지원합니다. 일괄 이름 변경은 작업당 최대 25개 파일이며, 변환은 작업당 원본 파일 1개와 하루 변환 파일 10개로 제한됩니다. Premium은 별도 구매로 이러한 에디션 제한을 해제합니다.

로컬 파일 관리에는 Atlas 계정이 필요하지 않습니다. 선택적 클라우드 연결에는 인터넷과 제공업체 계정이 필요합니다. 일부 미리 보기와 변환에는 추가 도구가 필요합니다. 암호화된 개인 폴더를 마운트하려면 선택적 WinFsp 드라이버가 필요합니다.
