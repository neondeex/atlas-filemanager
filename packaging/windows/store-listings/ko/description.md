Atlas File Manager는 Windows용 파일 탐색기입니다. 폴더를 탭으로 열고, 두 개의 창을 나란히 두고 작업하며, 하위 폴더까지 검색하고, 창을 벗어나지 않고 파일을 미리 볼 수 있습니다. 대부분의 작업에 키보드 단축키가 있으며 모든 명령을 하나의 검색으로 찾을 수 있습니다.

• 각각 고유한 보기와 기록을 유지하는 탭과 분할 창
• 폴더와 모든 하위 폴더 검색
• 파일 목록 옆에서 이미지, PDF, Markdown, 텍스트, 코드 미리 보기
• 형식 링에서 파일 변환(예: JPG를 PNG, WebP, PDF로)
• ZIP 압축 파일을 폴더처럼 열고 내용 미리 보기
• 자세히, 격자, 목록, 열, 트리 보기
• 모든 작업과 단축키를 보여 주는 명령 팔레트
• 변경 가능한 키보드 단축키와 검색 가능한 설정
• 사이드바의 Google Drive, OneDrive, SFTP, FTP, WebDAV, SMB
• 실시간 미리 보기를 지원하는 라이트, 다크, 글래스 테마
• 정리하기 전에 큰 폴더를 검토하는 디스크 사용량 맵
• 패턴과 번호를 사용한 일괄 이름 변경
• 선택 사항: 파일 탐색기 대신 Win+E로 Atlas 열기

Free는 최대 창 2개, 저장된 연결 1개, 프로필 2개를 지원합니다. 일괄 이름 변경은 작업당 최대 25개 파일이며, 변환은 작업당 원본 파일 1개와 하루 변환 파일 10개로 제한됩니다. Premium은 별도 구매로 이러한 에디션 제한을 해제합니다.

로컬 파일 관리에는 Atlas 계정이 필요하지 않습니다. 선택적 클라우드 연결에는 인터넷과 제공업체 계정이 필요합니다. 일부 미리 보기와 변환에는 추가 도구가 필요합니다. 암호화된 개인 폴더를 마운트하려면 선택적 WinFsp 드라이버가 필요합니다.
