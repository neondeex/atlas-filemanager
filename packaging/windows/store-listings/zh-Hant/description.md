Atlas File Manager 是一款 Windows 檔案總管。在分頁中開啟資料夾，並排使用兩個窗格，在子資料夾中搜尋，而且不必離開視窗即可預覽檔案。大多數操作都有鍵盤快速鍵，所有命令都能透過一次搜尋找到。

• 分頁和分割窗格，每個窗格保留各自的檢視和歷程記錄
• 在資料夾及其所有子資料夾中搜尋
• 在檔案清單旁預覽圖片、PDF、Markdown、文字和程式碼
• 從格式環中轉換檔案，例如將 JPG 轉為 PNG、WebP 或 PDF
• 像資料夾一樣開啟 ZIP 壓縮檔並預覽內容
• 詳細資料、格狀、清單、直欄和樹狀檢視
• 列出所有操作及其快速鍵的命令選擇區
• 可自訂的鍵盤快速鍵和可搜尋的設定
• 側邊欄中的 Google Drive、OneDrive、SFTP、FTP、WebDAV 和 SMB
• 支援即時預覽的淺色、深色和玻璃佈景主題
• 磁碟用量圖，在清理前檢視大型資料夾
• 使用模式和編號批次重新命名
• 選用：按 Win+E 開啟 Atlas，而非檔案總管

Free 版最多支援 2 個窗格、1 個已儲存連線和 2 個設定檔。批次重新命名每次最多 25 個檔案；轉換每次支援 1 個來源檔案，每天最多轉換 10 個檔案。Premium 需另外購買，可解除這些版本限制。

管理本機檔案無需 Atlas 帳戶。選用的雲端連線需要網際網路及服務供應商帳戶。部分預覽和轉換需要額外工具。掛載加密私人資料夾需要選用的 WinFsp 驅動程式，日常檔案管理無需此驅動程式。
