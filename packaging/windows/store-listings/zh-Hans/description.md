Atlas File Manager 是一款 Windows 文件资源管理器。在标签页中打开文件夹，并排使用两个窗格，在子文件夹中搜索，并且无需离开窗口即可预览文件。大多数操作都有键盘快捷键，所有命令都可以通过一次搜索找到。

• 标签页和分栏，每个窗格保留各自的视图和历史记录
• 在文件夹及其所有子文件夹中搜索
• 在文件列表旁预览图片、PDF、Markdown、文本和代码
• 从格式环中转换文件，例如将 JPG 转为 PNG、WebP 或 PDF
• 像文件夹一样打开 ZIP 压缩包并预览内容
• 详细信息、网格、列表、分栏和树状视图
• 列出所有操作及其快捷键的命令面板
• 可自定义的键盘快捷键和可搜索的设置
• 侧边栏中的 Google Drive、OneDrive、SFTP、FTP、WebDAV 和 SMB
• 支持实时预览的浅色、深色和玻璃主题
• 磁盘用量图，在清理前查看大型文件夹
• 使用模式和编号批量重命名
• 可选：按 Win+E 打开 Atlas，而不是文件资源管理器

Free 版最多支持 2 个窗格、1 个已保存连接和 2 个配置文件。批量重命名每次最多 25 个文件；转换每次支持 1 个源文件，每天最多转换 10 个文件。Premium 需单独购买，可解除这些版本限制。

管理本地文件无需 Atlas 账户。可选的云连接需要互联网和相应服务商的账户。部分预览和转换需要额外工具。挂载加密私人文件夹需要可选的 WinFsp 驱动程序，日常文件管理无需此驱动。
